# audit/ — review channel

So a reviewer working only from the published repository can check this wiki
without the session that built it. Git is the transport: `reports/` is mine,
`replies/` is yours.

## What to check, in order of how much a wrong answer costs

1. **Is the German→English translation faithful on technical terms?** This is
   the highest-value check and needs German *and* the physics. The register is
   dense with coinages — *Hermetrieform* → "form of hermetry", *Kondensorfluß* →
   "condenser flux", *Weltselektor* → "world selector", *Syntrometrie* →
   "syntrometry". Each concept page carries the German beneath the English
   precisely so this is checkable without the book.
2. **Is each German term paired with the right English one?** Entry boundaries
   were parsed from the English, because German capitalises every noun and a
   Title-case scan steals the previous definition's tail. The pairing was then
   fixed by sequence alignment, not by understanding. A mispairing would put one
   term's German under another's English. See `OPEN-QUESTIONS.md` item 2.
3. **Do the `→` cross-references link to the term the authors meant?** They were
   resolved by longest-match against the term index. A wrong link silently
   rewrites a definition's meaning.
4. **Are the formula readings right?** 662 numbered equations across the four
   volumes, as LaTeX. The scans are no longer in the wiki (they flooded llmwiki's
   Recent view), so each formula carries its unit id — the crop is in the drill
   folder under that name if you need to compare.

## What is already verified, so you need not re-derive it

`verification.json`, generated by `build/verify.py`:

| check | result |
|---|---|
| Markdown pages | 568 |
| maths expressions compiling under KaTeX | 4063 / 4063 |
| broken links or images | 0 |
| unreferenced pages | 0 |
| volumes represented | 4 |

**These are structural checks. They say nothing about whether a translation is
right** — that is what this review is for.

## How to reply

One file per review in `audit/replies/`, named `YYYY-MM-DD-<topic>.md`, from
`replies/TEMPLATE.md`. Commit it; anything under `replies/` is yours.

Please separate:

- **Defect** — a translation or link that is wrong, with the evidence.
- **Unsupported** — may be right, but nothing here backs it.
- **Judgement** — you would have chosen differently. Useful, but not a defect
  unless you can show harm.

If you need the source volumes to judge something, say so rather than guessing:
the verbatim extractions are not published.

## What is not in the repository

- `raw/` — verbatim full-text extractions of the four volumes. Third-party
  copyrighted works; excluded.
- `build/tw/` — TiddlyWiki working tree, rebuildable.

See the README on what the register pages nonetheless reproduce.
