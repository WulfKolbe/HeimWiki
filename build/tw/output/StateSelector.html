1. State selector
    • German:** *Zustandsselektor*

A Hermitian functional selector that is the metronic analogue of the state operator. If the state selector acts on a field selector that generates a convergent metronic state function, then the eigenvalues form a discrete point spectrum analogous to quantum states, because an abstract function space exists for both the state selector and the relevant field selector. For example, the space condenser is such a state selector whose eigenvalues form a discrete point spectrum as condensation levels, while the action of the fundamental condenser provides the metronic state function. The states described by the spatial condenser in the world selector are thus metric states of the world tensor itself, which occur in discrete condensation stages and form a point spectrum. Thus, this world tensor appears as a six-dimensional carrier space of the relevant abstract function space.
