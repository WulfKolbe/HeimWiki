1. Selector
    • German:** *Selektor*

A selection rule that selects function values from the set of positive integers or generates them over a more general number field.

**Original (German)**
Eine Auswahlregel, die aus der Menge positiver ganzer Zah len Funktionswerte auswählt oder über einem allgemeineren Zahlen körper erzeugt.
