1. Action Matrix
    • German:** *Wirkungsmatrix*

The set, arranged in a rectangular scheme, of all possible condenser field selectors for a given condenser signature. Action matrix, total: A hypermatrix that encompasses all possible action matrices (corresponding to the condenser signatures).

**Original (German)**
Die in einem Rechtecksschema angeordnete Gesamt heit aller zu einer Kondensorsignatur möglichen → Kondensfeldselek toren. Wirkungsmatrix, total: Eine Hypermatrix, die alle überhaupt mögli chen Wirkungsmatrizen (den → Kondensorsignaturen entsprechend) umfaßt.
