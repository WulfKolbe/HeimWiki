The $Q_{j}=$ const values obviously form a constant framework structure  for which $Q_{j}>0$ always holds. However, this requirement does not hold for the time-varying $n_{j}$, for which, in addition to $n_{j} \geqq 0$, $n_{j}<0$ may also be possible, whereby these “antiprotosimplex elements” eliminate corresponding elements of the framework structure. This, however, imposes a lower bound on the $n_{j}<0$; since $N_{(j)}$ is the integer that determines the protosimplex filling of the configuration zone $j$, $N_{(j)} \geqq 0$ must remain, because $N_{(j)}<0$ would imply a negative assignment  of $R_{3}$ with real elements. Thus, $N_{(j)}=n_{j}+Q_{j} \geqq 0$ holds, so that the lower bound is $\left(n_{j}\right)_{\text {min }}=-Q_{j}$. This minimum, denoted by $N_{(j)}=0$, thus corresponds to the empty $R_{3}$, which contains neither ( $\pm p$ ) nor ( +7 ) in the domain under consideration. On the other hand, however, this is the state of the imaginary $V_{6}$ reference point, such that this reference point in the $R_{3}$ can be expressed by the freedom of configuration $N_{(j)}=0$.
