Empirically, the interaction fields are classified into four classes based on their strength; however, it is possible that within one of these classes there are interaction fields of different natures that cannot currently be distinguished empirically. In a structural description, therefore, the value $n$ of the interaction fields, so that the value of $n$—which is actually still unknown—remains open. If each of these fields is now conceived as a  spacetime state (event structure), then there must be a geodesic reference frame for each  of these fields in which a line element of a vector nature characterizes the structural properties of the field. Due to the existence of conservation principles, the permitted coordinate transformations must all satisfy the general global Poincaré group, although local subgroups, so to speak, confer “identity” on each field. Now, since all $n$ fields act in every region of spacetime, a general line element is formed by summing the vectorial line elements, the square of which can be understood as the metric of the event structure. In general, gauge invariance can be established for a subset of the $n \geqq 4$ fields, but there is at least one non-gauge-invariant field, namely that of gravity. In general, one can thus conceive of $m \geqq 1$ non-gauge-invariant and $n-m>0$ gauge-invariant fields, where $n$ and $m$ lie in $1 \leqq \mathrm{~m}<n$ and $4 \leqq n<\infty$, but are otherwise unknown.
