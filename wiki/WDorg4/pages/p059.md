Since indeterministic quantum theory can be explained in this way using hyperspace dynamics, it seems essential to explicitly examine the individual elements of the mapping chain, with the individual steps labeled I) through IV). 
I): $\mathrm{G}_{4}\left(\mathrm{x}_{9}, \ldots, \mathrm{x}_{12}\right) \rightarrow \mathrm{R}_{\mathrm{n}}^{*}\left(\mathrm{y}_{1}, \ldots, \mathrm{y}_{\mathrm{n}}\right)$. 

Already in [Resch1989](../references/WDorg4_REF_Resch1989.md), a space $\mathrm{R}_{\mathrm{n}}^{*}$ emerged, which, as a mediating space  with $\mathrm{n} \rightarrow \infty$ and dimensionless coordinates, represents an analogue to the abstract function space. In $\mathrm{R}_{\mathrm{n}}^{*}\left(\mathrm{y}_{1}, \ldots, \mathrm{y}_{\mathrm{n}}\right)$, $\left[\mathrm{y}_{\mathrm{j}}^{2}\right]=\mathrm{m} / \mathrm{m}$ holds. If v denotes the set of integers $-\infty<\mathrm{v}<+\infty$, then $\mathrm{n}=2 \mathrm{v}+1$ can be used as an index, so that $R_{n}^{*}=R_{2 v+1}^{*}\left(y_{-v} \ldots y_{0}, y_{1} \ldots y_{v}\right)$ can be set. For the mapping $\mathrm{G}_{4} \rightarrow \mathrm{R}_{\mathrm{n}}^{*}$, a compactification can be assumed, so that, according to [Wissenschaft1984b](../references/WDorg4_REF_Wissenschaft1984b.md), a $\mathrm{G}_{4}$ function $\mathrm{A}\left(\mathrm{x}_{9} \ldots \mathrm{x}_{12}\right)$ to the  compactified version $\mathrm{A}\left(\mathrm{x}_{9} \ldots \mathrm{x}_{12}\right) \rightarrow \operatorname{Bexp}\left(\mathrm{i}\left(\mathrm{x}_{9}^{*}+\mathrm{x}_{10}^{*}+\mathrm{x}_{11}^{*}+\mathrm{x}_{12}^{*}\right)\right)$  with $\mathrm{x}_{\mathrm{m}}^{*}=\mathrm{x}_{\mathrm{m}} / \mathrm{x}_{\mathrm{mo}}$ and $\mathrm{m}=9 \ldots 12$ as well as $\mathrm{B}=$ const, where the $\mathrm{x}_{\mathrm{mo}}=$ const are suitable reference variables with $\left[\mathrm{x}_{\mathrm{m}}\right]=\left[\mathrm{x}_{\text {mo }}\right]$. For the time being, let  be set to $\mathrm{x}_{10}=\mathrm{x}_{11}=\mathrm{x}_{12}=0$ for clarity, so that initially  becomes $\mathrm{A}\left(\mathrm{x}_{9}\right) \rightarrow \mathrm{Bexp}\left(\mathrm{ix}_{9}^{*}\right)$. With the indexing $\mathrm{n}=2 \mathrm{v}+1$ , $\operatorname{Bexp}\left(\mathrm{ix}_{9}{ }^{*}\right)=\mathrm{f}$ can thus be assigned to a one-dimensional manifold $\mathrm{R}_{1}^{*} \in \mathrm{R}_{2 \mathrm{v}+1}^{*}$, so that, for example, $\mathrm{y}_{\mathrm{o}}^{2}=\mathrm{f}$ holds. The transition $\mathrm{A}\left(\mathrm{x}_{9}\right) \rightarrow \mathrm{f}$ yields only a specific, but not an arbitrary, one-dimensional function, which, however, would be required for the general case. On the other hand, A( $\mathrm{x}_{9}$ ) can also be mapped to a multitude of one-dimensional manifolds $\mathrm{R}_{1}^{*}$ provided that the reference lengths $\mathrm{x}_{\mathrm{mo}}$ depend on an index q, such that, for example, $\mathrm{x}_{9}^{\mathrm{q} *}=\mathrm{x}_{9} / \mathrm{x}_{9 \mathrm{o}}^{\mathrm{q}}$ is obtained. Since $B=$ is also freely available for the time being, $y_{q}^{2}=B_{q} \exp \left(i x_{9}^{q *}\right)$ can therefore be written. Thus, if $\mathrm{R}_{2 \mathrm{v}+1}^{*}$ is given, the sum $\mathrm{F}=\sum_{\mathrm{q}=-\infty}^{\infty} \mathrm{B}_{\mathrm{q}} \exp \left(\mathrm{ix}_{9}^{\mathrm{q} *}\right)$ results due to $\mathrm{F}=\sum_{\mathrm{q}=-\infty}^{\infty} \mathrm{y}_{\mathrm{q}}^{2}$, in which $\mathrm{F}\left(\mathrm{x}_{9}\right)$ is constructed from a finite number of length elements that, in the form $\mathrm{x}_{9}^{\mathrm{q} *}$, ultimately trace back to the integer indices q. On the other hand, $\left|\mathrm{y}_{\mathrm{q}}^{2}\right|>\left|\mathrm{y}_{\mathrm{q}+1}^{2}\right|$ may hold for all q, so that F can be regarded as a convergent series.  Consequently, there exists an upper bound $|\mathrm{q}| \leq \mathrm{M}<\infty$ beyond which the series terms contribute only very small amounts to the sum; these terms can therefore be approximately neglected in terms of the series’ convergence to a given function.
