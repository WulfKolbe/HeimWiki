It initiates a search for $\mathrm{K}_{\mathrm{m}} \subset \mathrm{K}_{12}$ using the variables from $\left(\mathrm{w}_{1}\right)$, whose secondary properties must first be identified. 

Using (11) and the set $\underline{\mathrm{D}}$, $\mathrm{w}_{0}=\mathrm{w}_{0}\left(\delta_{4}\right)$ is determined using $\mathrm{m} \delta_{4}=1$ and further  $\mathrm{w}_{1}=\mathrm{w}_{1}\left(\mathrm{~g}_{1}, \mathrm{~g}_{2}, \mathrm{~g}_{3}^{*}\right)=\mathrm{w}_{1}\left(\delta_{21}, \delta_{22}\right)$ if $\mathrm{g}_{3}^{*}$ is omitted. (Here, $\delta_{21}, \delta_{22}$ denotes indexed $\delta_{2}$ values.) For $\mathrm{w}_{2}$, 
$\mathrm{w}_{2}=\mathrm{w}_{2}\left(\mathrm{~g}_{1}, \mathrm{~h}_{1}, \mathrm{k}_{1}\right)=\mathrm{w}_{2}\left(\delta_{21}, \delta_{51}, \delta_{31}\right)=\mathrm{w}_{2}\left(\delta_{21}, \delta_{11}, \delta_{31}, \delta_{32}\right)$ then follows, whereby the second  index is used in the form already discussed to distinguish between sets. Here, the relation $\delta_{5}=\delta_{1}+\delta_{3}$ can be used. The $\delta_{\mathrm{j}}$, on the other hand, result from A (8) of (11) with $1+3=\delta_{1}$,  $5+7=\delta_{2}, 11+13=\delta_{3}$. Similarly, 
$\mathrm{w}_{3}=\mathrm{w}_{3}\left(\mathrm{w}_{3 \alpha}\left(\mathrm{~h}_{1}, \mathrm{~h}_{2}\right), \mathrm{w}_{3 \beta}\left(\mathrm{k}_{1}, \mathrm{k}_{2}\right)\right)=\mathrm{w}_{3}\left(\delta_{11}, \delta_{31}, \delta_{32}\right)$ follows, where this result  stems from the fact that, by analogy with $\mathrm{w}_{0}$ through $\mathrm{w}_{2}$, the set of variables is restricted only  to $\mathrm{w}_{3}$, but not to $\mathrm{w}_{3 \alpha}, \mathrm{w}_{3 \beta}$. In the form of an arithmetic  mean, this results in a dependence on h and k alone. The sets of variables from $\mathrm{w}_{0}$ to $\mathrm{w}_{3}$ were therefore chosen in the form given above in order to keep the union of the listed sets of variables small enough  to allow a $\mathrm{K}_{\mathrm{m}}$ symmetry can be extracted. This means that $\mathrm{w}_{4}$  is no longer included, because otherwise the set of variables—unlike $\mathrm{K}_{\mathrm{m}} \subset \mathrm{K}_{12}$—would extend beyond the complex $\mathrm{K}_{12}$. 

If we consider the elements $\delta_{\mathrm{x}}$ in the set of variables $\mathrm{V}_{\mathrm{a}}$ of the set  $\left(\mathrm{w}_{1}, \mathrm{w}_{2}\right)$, that is, $\mathrm{V}_{\mathrm{a}}=\left\{\left(\delta_{11}\right),\left(\delta_{31}, \delta_{32}\right),\left(\delta_{21}, \delta_{22}, \delta_{23}\right)\right\}$, it becomes apparent that this set is also structured and yields $\left\|\mathrm{V}_{\mathrm{a}}\right\|=\{1 ; 2 ; 3\}=\mathrm{K}_{6}$, i.e., the same $\mathrm{K}_{6}$ symmetry appears here, which also determines the structure of the metric coordinate set of $\mathrm{R}_{6}$. This means that, since according to [Resch1989](../references/WDorg4_REF_Resch1989.md), the $\mathrm{R}_{6}$ coordinates (unlike $\mathrm{R}_{12} \supset \mathrm{R}_{6}$ ) are defined in terms of energy, that the coupling constants $\mathrm{w}_{1}$ and $\mathrm{w}_{2}$ from (16) relate to the fields of the $\mathrm{R}_{6}$ hermetic forms, of which, according to [Resch1989](../references/WDorg4_REF_Resch1989.md), the forms a through d exist, whereby the hermetic forms for the self-condensations beyond  spacetime are $\stackrel{\wedge}{=}\left(\mathrm{x}_{5}, \mathrm{x}_{6}\right)$, and for the time condensations (photons) $\mathrm{b} \stackrel{\wedge}{=}\left(\mathrm{x}_{4}, \mathrm{a}\right)$, for  spacetime condensations (neutral particles) $\mathrm{c} \triangleq\left(\mathrm{R}_{3}, \mathrm{a}\right)$, and for the  spacetime condensations of electrically charged particles $\mathrm{d} \hat{=}\left(\mathrm{R}_{3}, \mathrm{x}_{4}, \mathrm{a}\right)$. Since the a-term appears, on average, as the $\mathrm{R}_{4}$ gravitational field, it is evident that $\mathrm{w}_{21}$ is the coupling constant of the b-field and $\mathrm{w}_{22}$ is that of the gravitational field, while $\mathrm{w}_{23}$ represents the strong force (nuclear force), and $\mathrm{w}_{24}$ for the weak force.
