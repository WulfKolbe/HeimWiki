For $\mathrm{w}_{1}$ and $\mathrm{w}_{2}$, the assignment scheme $\mathrm{w}_{1}, \mathrm{w}_{2}:\left(\mathrm{g}_{1}, \mathrm{~g}_{2}, \mathrm{~g}_{3}\right),\left(\mathrm{g}_{1}, \mathrm{~h}_{1}, \mathrm{k}_{1}\right),\left(\mathrm{g}_{1}, \mathrm{~g}_{2}, \mathrm{~g}_{3}\right)$ applied, where the sets $\mathrm{w}_{0}(\mathrm{~m})$ are followed by $\mathrm{w}_{1}$  and $\mathrm{w}_{2}$ can follow, which corresponds to the sequence of the element g to the element m in $\mathrm{U}_{0}$. If we take into account the mapping principles of ordered sets, then it is clear that the elements of the sets $\mathrm{w}_{0} \ldots \mathrm{w}_{4}$ can be uniquely expressed by the elements of $\mathrm{U}_{0}$ or $\mathrm{U}_{\mathrm{a}}$ from (11) in a unique way. However, it is not only this set or Dz from  (14) that is relevant, but also the structured set of operations  $\mathrm{V}=\left\{\left(\mathrm{o}_{1}\right),\left(\mathrm{o}_{2} \mathrm{o}_{1}\right),\left(\mathrm{o}_{3} \mathrm{o}_{2} \mathrm{o}_{1}\right),\left(\mathrm{o}_{4} \mathrm{o}_{3} \mathrm{o}_{2} \mathrm{o}_{1}\right)\right\}$, for which the cardinality complex  $\|\mathrm{V}\|=\{1 ; 2 ; 3 ; 4\}=\mathrm{K}_{10} \subset \mathrm{~K}_{12}$ holds. If $\|\underline{\mathrm{V}}\|=\mathrm{K}_{12}$ is to be defined, two more operations must be added to V, resulting in V. Since, due to the set property of V, there can be no further two-element  combination operation $\left(\mathrm{o}_{2} \mathrm{o}_{1}\right)$ with respect to the primitive elements, the elements to be added must be operations that each act on only one numerical element of $\mathrm{U}_{0}$. If these two elements are denoted by $\mathrm{f}_{1}$ and $\mathrm{f}_{2}$, then the set of operations thus completed is $\underline{\mathrm{V}}=\left\{\left(\mathrm{o}_{1}\right),\left(\mathrm{o}_{2} \mathrm{o}_{1}\right),\left(\mathrm{o}_{3} \mathrm{o}_{2} \mathrm{o}_{1}\right),\left(\mathrm{o}_{4} \mathrm{o}_{3} \mathrm{o}_{2} \mathrm{o}_{1}\right),\left(\mathrm{f}_{1}, \mathrm{f}_{2}\right)\right\}$. The operations $\mathrm{f}_{1}$ and $\mathrm{f}_{2}$ each act on a single element of the sets $\mathrm{w}_{0} \ldots \mathrm{w}_{4}$. The calculus of cardinal numbers and the possibility of power representation $\left\|\mathrm{M}^{\mathrm{q}}\right\|=\mathrm{m}^{\mathrm{q}}$,  if m and q are cardinal numbers, suggest the two operations $f_{1}=()^{\alpha}$ and $f_{2}=()^{\beta}$. We shall now refer to the power set $L$ from [Resch1989](../references/WDorg4_REF_Resch1989.md), which was used to determine dimensional numbers expressed as exponents of element lengths. 

The operation $(+\cdot)$ led there to $\mathrm{x}+\mathrm{x}^{2}-2=0$ or $\mathrm{x}_{(1)}=1$ and  $\mathrm{x}_{(2)}=-2$, that is, to the superscripts 1 and -1/2. $1 / \mathrm{x}_{(1)}=1$ represented the dimension of the time structure $\mathrm{T}_{1}\left(\mathrm{x}_{4}\right)$ from $\mathrm{R}_{6}=\mathrm{R}_{3} \cup \mathrm{~T}_{1} \cup \mathrm{~S}_{2}$, but $1 / \mathrm{x}_{(2)}=-1 / 2$ for the dimension $1 / 2 \mathrm{n}$ of the mediator space $\mathrm{R}_{\mathrm{n}}^{*}$. For the exponent $\alpha$, $\alpha=-1 / \mathrm{x}_{(2)}=1 / 2$ is therefore a suitable choice. Among the elements present in L, $3=\operatorname{dim}\left(\mathrm{R}_{3}\right)$ is also a good choice due to its proximity to $\mathrm{x}_{4}$, which makes $\beta=3$ likely. With $\alpha=1 / 2$ and $\beta=3$ the operators $\mathbf{f}_{1}$ and $\mathbf{f}_{2}$ are already uniquely determined, so that V with the $\mathrm{K}_{12}$ symmetry is now uniquely complete. Using the operations of V, $\mathrm{w}_{0}$ through $\mathrm{w}_{4}$ can therefore be explicitly expressed in a numerically computable form using the primordial elements.
