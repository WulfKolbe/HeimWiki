If primordial elements of a sequence of sets that can be represented by cardinal numbers are to be assigned to $\mathrm{a}_{1} \ldots \mathrm{a}_{\mathrm{n}}$, it seems sensible to first examine the concept of the dimensional number in the set-theoretical sense.  Since dimensional numbers, as pure numbers, are physically very elementary,  it should be mathematically possible to determine them. At the cosmogonic origin of the world, that is, at the time $\mathrm{t}=0$, only the simplest physical  process could have been initiated, which, as already shown in [Resch1984](../references/WDorg4_REF_Resch1984.md), is characterized by only  a few concentric spherical surfaces of a monometrical nature. The coupling constants, which are physically observed in the present age of the universe, must also be present at the boundary time $t=0$ due to their apparent timelessness and can therefore be represented by what is likely a very small number of parameters. To find these parameters, one must therefore, in a higher-order set-theoretical sense, search for a set of numbers that is not the superset of an even simpler subset. According to this criterion, only the set P of prime numbers remains, which is a subset of the set of natural numbers N, that is, $\mathrm{P} \subset \mathrm{N}$. If P is ordered according to $\mathrm{p}_{\mathrm{i}+1}>\mathrm{p}_{\mathrm{i}}$, then a finite subsequence can be obtained from this ascending infinite sequence $\mathrm{p}_{\mathrm{i}}$ if the termination condition for a limit $\mathrm{i}=\mathrm{i}_{\mathrm{o}}<\infty$ of the sequence can be specified. Now, for the structured set of $\mathrm{R}_{12}$-coordinates, the cardinal number complex $\mathrm{K}_{12}=\{3 ; 1 ; 2 ; 2 ; 4\}$ holds, so that, for the determination of the termination condition, a $\mathrm{K}_{12}$ symmetry is initially required. 

If $\mathrm{P}=\left\{\mathrm{p}_{1}, \ldots\right\}$ is ordered in ascending order according to $\mathrm{p}_{\mathrm{i}+1}>\mathrm{p}_{\mathrm{i}}$, then, as is well known, $\mathrm{P}=\{1,2,3,5,7,11,13,17,19, \ldots\} \subset \mathrm{N}$ holds.
