Particles interact with antiparticles, which slightly alter $\sqrt{\alpha_{1}^{\prime}}$. In any case, the agreement between $\sqrt{\alpha_{1}^{\prime}} \quad\left(\mathrm{E}_{4}\right)=0,08644$ and $\mathrm{w}_{21}\left(\mathrm{E}_{4}\right)=0,086433$ is very good. 

For the strong interaction, the sliding interaction constant $\alpha_{4}^{\prime}$ (E) be determined according to [Mannheim1989](../references/WDorg4_REF_Mannheim1989.md), which can then be compared with $\underline{\alpha}_{4}(\mathrm{E})$. 
From [Mannheim1989](../references/WDorg4_REF_Mannheim1989.md), we now obtain $\alpha_{4}^{\prime}(\mathrm{E})=\frac{12 \pi}{\left(33-2 \mathrm{n}_{\mathrm{F}}\right) \ln (\mathrm{E} / \Lambda)^{2}}$, where $\mathrm{n}_{\mathrm{F}}$  is the number of components involved in the interaction, and $\Lambda$ is a scaling parameter that, however, depends, among other things, on $\mathrm{n}_{\mathrm{F}}$. If one takes into account that, according to [2, Chap. VIII], $\mathrm{k}+1$ quasi-corpuscular subconstituents always structure a term of the c- or d-spectra—i.e., 3 for $\mathrm{k}=2$ (baryons), then a total of 6 subconstituents are involved in a nucleon -nucleon interaction (specifically proton-proton), so that in the relation $\mathrm{n}_{\mathrm{F}}=6$, i.e., $33-2 \mathrm{n}_{\mathrm{F}}=21$, must be set. From the experimentally measured value $\Lambda^{\left(\mathrm{n}_{\mathrm{F}}=4\right)}=0,2_{-0,08}^{+0,15} \mathrm{GeV}$ from [Mannheim1989](../references/WDorg4_REF_Mannheim1989.md), $\Lambda^{\left(\mathrm{n}_{\mathrm{F}}=6\right)}=0,395 \mathrm{GeV}$ can then be determined using [Mannheim1989](../references/WDorg4_REF_Mannheim1989.md). Using $\mathrm{E}=\mathrm{E}_{2}=0,7824 \mathrm{GeV}$, we finally obtain $\alpha_{4}^{\prime}\left(\mathrm{E}_{2}\right)=1,312$, which differs by approximately $\delta \underline{\alpha}_{4}=16 \cdot 10^{-2}$ from $\underline{\mathbf{w}}_{23}^{2}\left(\mathrm{E}_{2}\right)=\underline{\alpha}_{4}\left(\mathrm{E}_{2}\right)=1,1352$. This discrepancy arises primarily due to the imprecise scaling parameter. If $\underline{\alpha}_{4}\left(\mathrm{E}_{2}\right)=\alpha_{4}^{\prime \prime}\left(\mathrm{E}_{2}\right)$ is used to recalculate $\underline{\Lambda}^{\left(\mathrm{n}_{\mathrm{F}}=4\right)}$ based on the now-unknown scaling parameter $\left(\alpha_{4}^{\text {" }}=\frac{12 \pi}{\left(33-2 \mathrm{n}_{\mathrm{F}}\right) \ln \left(\mathrm{E}_{2} / \underline{\Lambda}\right)^{2}}\right)$, then $\underline{\Lambda}^{\left(\mathrm{n}_{\mathrm{F}}=4\right)}=0,183$ is obtained, which lies well within the bounds set by $\Lambda^{\left(\mathrm{n}_{\mathrm{F}}=4\right)}$. Consequently, the terms from (21) are assigned to the interactions (22) as follows:
