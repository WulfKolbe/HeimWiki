In the preceding section, the chain $\mathrm{K}_{4} \subset \mathrm{~K}_{6} \subset \mathrm{~K}_{8} \subset \mathrm{~K}_{12}$ of cardinal number complexes was used in accordance with the subspaces $\mathrm{R}_{4} \subset \mathrm{R}_{6} \subset \mathrm{R}_{8} \subset \mathrm{R}_{12}$. Since the following holds for the spacetime ordinal number complex $\mathrm{Or}_{4}=\{1 ; 3\}$, there must be a degeneration $\mathrm{K}_{1}=\{1\}$ such that the chain is bounded below in this way according to 
$\mathrm{K}_{1} \subset \mathrm{~K}_{4} \subset \mathrm{~K}_{6} \subset \mathrm{~K}_{8} \subset \mathrm{~K}_{12}$ is bounded below in this way, which immediately raises the question of whether there is also an upper bound beyond the $\mathrm{K}_{12}$ , especially since in the Apeiron there exists a $\mathrm{R}_{28}$ and U from (11) also exhibits a preforming algebraic structure prior to its entry into temporality (11a). 

If we first consider the ordered set $\mathrm{U}_{0}=\{(\mathrm{m}),(\mathrm{g}, \mathrm{h}, \mathrm{k}),(\mathrm{n}, \mathrm{p})\}$ of the primordial elements, i.e., $\left\|\mathrm{U}_{0}\right\|=\{1 ; 3 ; 2\}=\mathrm{K}_{6}$, it becomes clear that in the chain $\mathrm{K}_{1} \subset \ldots \subset \mathrm{~K}_{12}$, following the complex $\mathrm{K}_{6}$, is followed by the complex $\mathrm{K}_{8}$, so that $\mathrm{U}_{0}$ would need to be supplemented by a further subset consisting of two elements. 

Now, in addition to $\mathrm{K}_{8}=\{1 ; 3 ; 2 ; 2\}$, the form $\underline{\mathrm{K}}_{8}=\{6 ; 2\}$ was also used,  because the energy-dependent coordinates of $\mathrm{R}_{6}=\mathrm{R}_{3} \cup \mathrm{~T}_{1} \cup \mathrm{~S}_{2}$ qualitatively differ from the non-energy-dependent coordinates in the $\mathrm{I}_{2}$ of $\mathrm{R}_{8}=\mathrm{R}_{6} \cup \mathrm{I}_{2}$. This difference also follows from the fact that, for the set  $\left\{\mathrm{x}_{1} \ldots \mathrm{x}_{6}\right\}$ of $\mathrm{R}_{6}$ coordinates, the time-dependent elementary lengths 
$\left|\delta \mathrm{x}_{\mathrm{i}}\right|=\delta \mathrm{s}_{0}(\mathrm{t})$ with ( $\mathrm{i}=1,2 \ldots 6$ ) exist, whereas for 
$\left|\delta \mathrm{x}_{7,8}\right|=\delta 1_{0} \exp (-24 \pi)$ of $\mathrm{R}_{8} \supset \mathrm{R}_{6}$, no such time dependence can be established. Thus, if $\mathrm{U}_{0}$ is supplemented with $\left\|\mathrm{U}_{0}\right\|=\mathrm{K}_{6}$ by the subset  of further primordial elements ( $\mathrm{r}, \mathrm{s}$ ), and if the ordinal number complex is transformed into this augmented set—that is, $\mathrm{Or}_{8}=\{1 ; 3 ; 2 ; 2\}$ is transformed into $\mathrm{Or}_{8}=\{6 ; 2\}$, then it becomes clear that the prime elements r and s must differ significantly from the elements of the set U from (11). The elements of this  structured primordial set resulted from dimensional numbers according to (1), so  that the conclusion suggests itself: ( $\mathrm{r}, \mathrm{s}$ ) would be composed of the simplest elements of a preexisting precursor in the apeiron, which provided the dimensional numbers. The simplest elements would then be the first two elements of the set A of primes, which is symmetric with respect to oddness—
