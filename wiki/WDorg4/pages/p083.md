Similar to how the ordinal number complex $\mathrm{Or}_{6}$ emerged from the ordered cardinal number complex $\mathrm{K}_{6}$  , the present, unordered $\mathrm{K}_{12}$ must also lead to such an ordinal number complex $\mathrm{Or}_{12}$. However, a cardinal number complex is also directly associated with a set of index numbers; for if a set M contains elements that are quantitatively equal but differ in their semantics, they can be distinguished by appropriate indexing. If, for example, $\mathrm{M}=\left\{\mathrm{a}_{1}, \mathrm{~b}_{1}, \mathrm{~b}_{2}, \mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}, \mathrm{~d}_{1}, \mathrm{~d}_{2}\right\}$ holds, then—due to $\mathrm{b}_{1} \approx \mathrm{~b}_{2}$ and $\mathrm{c}_{1} \approx \mathrm{c}_{2} \approx \mathrm{c}_{3}$ and $\mathrm{d}_{1} \approx \mathrm{~d}_{2}$, the respective indexed elements can be approximated to the identity and distinguished from one another only by arbitrarily small deviations. This results in a subset structure for $M$ of the form $\mathrm{M}=\left\{\left(\mathrm{a}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}\right),\left(\mathrm{d}_{1}, \mathrm{~d}_{2}\right)\right\}$,  for which the cardinal number complex $\{1 ; 2 ; 3 ; 2\}=\mathrm{K}_{8}$ holds. 

If, in a structured set, the subsets are denoted by $\mathrm{M}_{\mathrm{p}}$, then on the one hand $\left\|\mathrm{M}_{\mathrm{p}}\right\|=\mathrm{m}_{\mathrm{p}}$ holds, but on the other hand $\mathrm{p}_{\mathrm{r}}=\operatorname{Max}\left\{\mathrm{ip}_{1}, \ldots, \mathrm{ip}_{\mathrm{r}}\right\}$ also holds,  where $\mathrm{ip}_{1} \ldots \mathrm{ip}_{\mathrm{r}}$ are the index numbers of the subset $\mathrm{M}_{\mathrm{p}}$, which in this case means $\mathrm{m}_{\mathrm{p}}=\mathrm{p}_{\mathrm{r}}$. Thus, in the example, $\left\|\left\{\mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}\right\}\right\|=3$ and $\operatorname{Max}\left\{\mathrm{i} 1_{1}, \mathrm{i} 1_{2}, \mathrm{i} 1_{3}\right\}=3$. Here, $\mathrm{ip}_{1} \ldots \mathrm{ip}_{\mathrm{r}}$ are the index numbers of the subset $\mathrm{M}_{\mathrm{p}}$,  which, due to their unbroken sequence of natural numbers in ascending order, can be represented by the representative $\mathrm{ip}_{\mathrm{r}}=\mathrm{p}_{\mathrm{r}}$. The set of index numbers for the example M would therefore be 
$\mathbf{I}=\left\{1_{1}, \ldots, 4_{2}\right\}=\{1,2,3,2\}$. Since I is defined as a set of numbers but not as a  complex, the duplicate element 2 must be removed once, which yields $I=\{1,3,2\}$ for the set of index numbers in the example.  The same result is obtained if the cardinal number complex  $\mathrm{K}_{8}=\|\mathrm{M}\|$ is interpreted as a set of numbers. 

With regard to the cardinal number complex $\mathrm{K}_{12}=\{3 ; 1 ; 2 ; 2 ; 4\}$, this yields the index number set $\mathrm{I}=\{3,1,2,4\}$. Similarly, the chain $\mathrm{K}_{4} \subset \mathrm{~K}_{6} \subset \mathrm{~K}_{8} \subset \mathrm{~K}_{12}$ is equivalent to the set chain of index numbers 
$\{1,3\} \subset\{1,3,2\} \subset\{1,3,2,4\}$, whereby $\operatorname{Or}_{12}=\{1 ; 3 ; 2 ; 2 ; 4\}$ is transformed into the ordered set of index numbers $\mathrm{I}_{0}=\{1,3,2,4\}$.
