The interaction fields contained in $\mathrm{A}=\mathrm{A}_{9}+\mathrm{A}_{1}+\mathrm{A}_{3}$ are of a spacetime nature—that is, energetic in nature—so that their coupling constants, according to (24), are elements of $\mathrm{K}_{\mathrm{E}}$. Furthermore, each interaction field is characterized by some form of  ponderable or imponderable Wq, which are exchanged between the field sources during the interaction process, whereby these  field sources (or sinks) can be assigned charge properties in the most general  sense. For the group $\mathrm{A}_{9}$, there must therefore be nine Wq, but for $A_{1}$ there must be only one Wq, and for $A_{3}\left(R_{3}, T_{1}\right)+A_{3}\left(T_{1}, R_{3}\right)$ six such quanta, which are reduced to 3 quanta if the fields assigned to $\mathrm{A}_{3}\left(\mathrm{R}_{3}, \mathrm{~T}_{1}\right)+\mathrm{A}_{3}\left(\mathrm{~T}_{1}, \mathrm{R}_{3}\right)$ assigned fields << 14 >> + << 24 >> + << 34 >> + << 41 >> + << 42 >> + << 43 >> are symmetrized by combining two fields each into a single field (e.g., << 14 >> + << 41 >>)  . These 3 new fields $\mathrm{A}_{3}$ then provide a means of unification with the symmetric field << 44 >>. If we consider the currently established interaction theories, which are based on empirical observations, then the group $\mathrm{A}_{9}$ to encompass the strong interactions, whose Wq might possibly be identical to the 9 postulated “gluons.” For $\mathrm{A}_{1}$, the electromagnetic interaction suggests itself as an interpretation, especially since, according to quantum electrodynamics, the photon is the only Wq of this interaction. The group $\mathrm{A}_{3}$, on the other hand, appears to contain the weak forces, for which three vector bosons are expected as Wq—bosons that have already been discovered through the empirical findings of high-energy physics. Each of these vector bosons appears to consist of 2 subconstituents. By analogy with these facts, it was already shown in [Resch1984](../references/WDorg4_REF_Resch1984.md) from the configuration number k—for which only k = 1 or $\mathbf{k}=2$ is possible, that each term of a theoretical particle spectrum is structured by configuration zones that form $\mathrm{k}+1$ quasi-corpuscular subconstituents, which in turn characterize the internal structure of the term. Here, too, there is a clear analogy to the likewise more  empirical model of “quarks,” although the empirical requirement of “confinement” becomes superfluous because the derived subconstituents are spatial components, i.e., $\mathrm{R}_{3}$ partial fluxes of a flux aggregate characterizing c or d hermetry in the $\mathrm{R}_{6}$tensor according to  [Resch1984](../references/WDorg4_REF_Resch1984.md). It should be noted that each of the $\mathrm{R}_{4}$ fields in A  can be coupled to a field from B and/or C.
