First, we consider a union set that, on the one hand, contains all subsets developed so far, but, on the other hand, satisfies a $\mathrm{K}_{12}$ symmetry with respect to its set elements and set of variables.  If, for each sequence of sets of a given level, a set of variables assigned to that level is used, then, if F denotes a union set, 
$\mathrm{F}=\left\{\left(\mathrm{a}_{1}\right),\left(\mathrm{b}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\left(\mathrm{c}_{1}\right)\right),\left(\left(\mathrm{c}_{1}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}\right)\right),\left(\left(\mathrm{c}_{1}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}\right)\right),\left(\left(\left(\mathrm{d}_{1}\right)\right)\right.\right.$,  $\left.\left.\left(\left(\mathrm{d}_{1}\right),\left(\mathrm{d}_{1}, \mathrm{~d}_{2}\right)\right)\right),\left(\left(\left(\left(\mathrm{e}_{1}\right)\right)\right), \ldots.\right)\right\}$ can be written. If the requirement of a  $\mathrm{K}_{12}$symmetry is imposed on F with respect to set elements of different structures, then $\left(\mathrm{b}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right)$ must be replaced by $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right) \mathrm{zu}$. For if the condition $\mathrm{a}_{1}=\mathrm{b}_{1}$ , then F contains two identical elements, so that according to the definition of a set (a collection of well-distinct objects), one of the two identical elements must be removed—in this case, $\left(\mathrm{b}_{1}\right)$. $\mathrm{b}_{3}^{*}$ expresses here that, through a set-theoretical process, a prime element $\mathrm{b}_{3}^{*}$ is added, meaning that $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right) \rightarrow\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right)$ holds. To avoid the aforementioned indistinguishability, $\left(\mathrm{b}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right)$ is then also transformed into $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right)$. 

A sequence of sets of a given level consisting of n terms can be represented by specifying the nth term. This means that the transition from $\mathrm{F} \rightarrow \underline{\mathrm{F}}$ to $\underline{\mathrm{F}}=\left\{\left(\mathrm{a}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right),\left(\left(\mathrm{c}_{1}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}\right)\right),\left(\left(\left(\mathrm{d}_{1}\right)\right)\right.\right.$ and $\left.\left.\left(\left(\mathrm{d}_{1}\right),\left(\mathrm{d}_{1}, \mathrm{~d}_{2}\right)\right)\right),\left(\left(\left(\left(\mathrm{e}_{1}\right)\right)\right), \ldots.\right)\right\}$ is feasible. 

Applying the previously defined combination operations $\mathrm{o}_{\mathrm{j}}$ then yields the five solutions symbolized by $\mathrm{w}_{0}$ through $\mathrm{w}_{4}$:

Wird an F nunmehr hin sichtlich verschieden strukturierter Mengenelemente die Forderung einer  $\mathrm{K}_{12}$-Symmetrie gestellt, dann ist $\left(\mathrm{b}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right)$ durch $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right) \mathrm{zu}$  ersetzen. Denn wird in F für die Elemente $\mathrm{a}_{1}=\mathrm{b}_{1}$ gesetzt, dann enthält F  zwei identische Elemente, so daß nach der Mengendefinition (Ansammlung  wohlunterschiedener Dinge) eines der beiden identischen Elemente zu ent fernen ist, und zwar im vorliegenden Fall $\left(\mathrm{b}_{1}\right)$. Durch $\mathrm{b}_{3}^{*}$ wird hier zum Aus druck gebracht, daß durch einen Mengenprozeß ein Urelement $\mathrm{b}_{3}^{*}$ hinzu kommt, also $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right) \rightarrow\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right)$ gilt. Zur Vermeidung der erwähnten  Nichtunterscheidbarkeit wird dann auch $\left(\mathrm{b}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right)$ in $\left(\mathrm{b}_{1}, \mathrm{~b}_{2}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right)$  überführt.

> Eine Mengenfolge vorgegebener Stufe, die aus n Gliedern besteht, kann  durch Angabe des Gliedes n repräsentiert werden. Dies bedeutet, daß der  Übergang $\mathrm{F} \rightarrow \underline{\mathrm{F}}$ mit $\underline{\mathrm{F}}=\left\{\left(\mathrm{a}_{1}\right),\left(\mathrm{b}_{1}, \mathrm{~b}_{2}, \mathrm{~b}_{3}^{*}\right),\left(\left(\mathrm{c}_{1}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}\right),\left(\mathrm{c}_{1}, \mathrm{c}_{2}, \mathrm{c}_{3}\right)\right),\left(\left(\left(\mathrm{d}_{1}\right)\right)\right.\right.$,  $\left.\left.\left(\left(\mathrm{d}_{1}\right),\left(\mathrm{d}_{1}, \mathrm{~d}_{2}\right)\right)\right),\left(\left(\left(\left(\mathrm{e}_{1}\right)\right)\right), \ldots.\right)\right\}$ durchführbar ist.
