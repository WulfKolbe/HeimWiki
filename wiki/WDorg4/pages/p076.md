The final operation $(+)$ in $\mathrm{O}_{\mathrm{p}}$ ultimately yields  $\mathrm{g}_{2}\left(\mathrm{a}_{1}\right)=(+)\left(\mathrm{a}_{1}, \mathrm{a}_{1}\right)=\mathrm{a}_{1}+\mathrm{a}_{1}=2 \mathrm{a}_{1}=2$, where the index k in $\mathrm{g}_{\mathrm{k}}$ denotes the number of elements in the set in parentheses. The resulting numbers can now be combined into a set M composed of subsets. The following representation holds for this set: 
$\mathrm{M}=\{(2),(1,4),(1,3,6),(4,12,24,28,36,48,64,72)\}$, from which the complex cardinality $\|\mathrm{M}\|=\{1 ; 2 ; 3 ; 8\}$ follows. If we omit the brackets of the sub sets in M, then the elements 1 and 4 appear twice, so they must be omitted once. The set then takes the form  $\underline{\mathbf{M}}=\{(2),(1,3,6),(4,12,24,28,36,48,64,72)\}$ with $\|\underline{\mathbf{M}}\|=\{1 ; 3 ; 8\}$. This symmetry follows from the $\mathrm{K}_{12}$ symmetry \{3; 1; 2; 2; 4\} by combining the last three terms $2+2+4=8$, from which it follows that the number of elements in $\mathrm{f}_{\mathrm{j}}\left(\mathrm{a}_{1}\right), \mathrm{f}_{\mathrm{i}}\left(\mathrm{a}_{2}\right)$ and $\mathrm{g}_{\mathrm{k}}\left(\mathrm{a}_{1}\right)$ is determined by this symmetry.  The removal of the elements (1, 4), which appear twice in M, means that $(+++) \rightarrow(++),(+)$ is no longer relevant, whereas $(++) \rightarrow(+)$ in (12) is. If the elements of $\underline{\mathrm{M}}$ are interpreted as dimension numbers, then in the Apeiron only $\mathrm{a}=1$ is initially present in the Apeiron, from which the combination operation (+++) forms the dimensional numbers 1 and 4, which in turn generate the numbers 
(1, 2, 3, 4, 6, 12, 24, 28, 36, 48, 64, 72). This set of numbers, consisting of twelve elements, can be divided into sub sets according to algebraic criteria. Thus, $1+2+3+6=12, \quad 12+24+28=64$ and $72-48=24$ hold, which means that sums or differences of dimensional numbers can in turn yield dimensional numbers; that is, sum and difference spaces exist. For the dimensional numbers $4=1+1+1+1$ or $4 \cdot 4 \cdot 4=64$, however, they can be represented as  (+) $\left(\mathrm{a}_{1}, \stackrel{2}{\mathrm{a}}_{1}, \stackrel{3}{\mathrm{a}}_{1}, \stackrel{4}{\mathrm{a}}_{1}\right)=4$ with $\stackrel{\mathrm{i}_{1}}{\mathrm{a}_{1}}$ or (•) $\left(\mathrm{a}_{2}, \stackrel{2}{\mathrm{a}}_{2}, \stackrel{3}{\mathrm{a}}_{2}\right)=64$ with $\stackrel{\mathrm{j}}{\mathrm{a}}_{2}=4$. Thus, the now-structured set of dimension numbers is given by $\mathrm{D}=\{(36),(12,28,24),(4,64),(48,72),(1,2,3,6)\} \operatorname{mit} \quad\|\mathrm{D}\|=\{1 ; 3 ; 2 ; 2 ; 4\}$, where || D || turns out to be a $\mathrm{K}_{12}$ symmetry.
