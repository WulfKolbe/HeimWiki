# Creation Selector

**German:** *Kreationsselektor*

This [functional selector](../concepts/FunctionalSelector.md) selects, from among all number-theoretic functions of an integer index, all those that, when interpreted as number sequences, form Fibonacci sequences.

<!--okf:source lang="de"-->
> **Original (German)**
>
> Dieser → Funktionalselektor wählt aus allen zah lentheoretischen Funktionen eines ganzzahligen Index alle diejenigen aus, die als Zahlenfolgen aufgefaßt, Fibonacci-Reihen bilden.
