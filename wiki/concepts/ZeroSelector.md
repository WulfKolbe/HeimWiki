# Zero selector

**German:** *Nullselektor*

A special [constant selector](../concepts/ConstantSelector.md) in which the constant has the value 0, such that the effect of this zero selector always yields 0. Operator, metronic: A computational rule that takes into account the [metron](../concepts/Metron.md) and can always be interpreted as a [selector](../concepts/Selector.md).

<!--okf:source lang="de"-->
> **Original (German)**
>
> Ein spezieller → Konstantenselektor, in welchem die Konstante den Wert 0 hat, so daß die Wirkung dieses Nullselektors stets 0 liefert. Operator, metronisch: Eine Rechenvorschrift unter Berücksichtigung des → Metrons, die stets als → Selektor aufgefaßt werden kann.
