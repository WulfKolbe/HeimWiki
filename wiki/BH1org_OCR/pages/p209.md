Similarly, $\lambda(k, l) \varepsilon_{k l}$ depends only on $\lambda_{m}(k, l)$ in this way, so that $\lambda(k, l) \varepsilon_{k l}=\lambda_{k l}$  can be introduced as a new spectrum of condensation stages.  The exponent thus simplifies to $\lambda(k, l) N_{k l}=\lambda_{k l} \mu ; n$. In this  solution, the two distinct branches must first be analyzed. Likewise, a determination of $C_{k l}$ is necessary. A universal determination of these integration constants of the partial solution to the fundamental Hermitian problem is apparently not possible;  for in any case, $C_{k l}$ must be adapted to the special class of Hermitian forms (imaginary or complex), which is, however, excluded in the general partial solution of the fundamental problem. 

The solution obviously holds for all $N_{k l}$ and must continue into the  infinitesimally approximated region, as well as be valid when the $\lambda(k, l)$ and $a(k, l)$ are such that $\lambda(k, l) \alpha_{s} \ll 1$, i.e., $\Lambda_{k l} \approx 0$. Thus, the approximation $\frac{1+u}{1-u}=C_{k l} e^{ \pm \lambda(k, l) N_{k l}}=f$ is given for selecting the branch. Using $u= \pm\left(\frac{2 \varphi_{k l}}{\lambda(k, l)}-1\right)$, the elimination yields $2 \frac{\varphi_{k l}}{\lambda(k, l)}= \pm \frac{f-1}{f+1}+1$.  The extrema of the curve $\varphi_{k l}$ are denoted by $\partial_{s} \varphi_{k l}=0$, which, when substituted into the hermetic fundamental problem, yields $\psi_{\text {ext }}^{(k l)}=\lambda(k, l)$, leading to $u_{\text {ext }}= \pm 1$. The non-approximated solution yields a non-divergent extremum $f_{\text {ext }}=0$ only for the lower sign, while the upper sign leads to a  singular value. Consequently, only the negative branch of $u$ can be considered, and this yields, with the normalized state function $\eta_{k l}=\frac{\varphi_{k l}}{\lambda(k, l)}$, the unique solution $\left(1-\eta_{k l}\right)^{\Lambda_{k l}+1} \eta_{k l}{ }^{\Lambda_{k l}-1}=2^{-2 \Lambda_{k l}} C_{k l} e^{-\lambda_{k l} N}$ with $N=\mu ; n$ and, for the approximation, $\eta_{k l} \approx\left(1+C_{k l} e^{-\lambda_{k l} N}\right)^{-1}$.
