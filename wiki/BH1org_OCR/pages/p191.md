This convergence, in turn,  makes the normalization $S_{\Omega} \varphi \varphi^{*} \overline{\partial \Omega}=1$ possible. Convergence of metronic state functions is thus, just like the reality of the eigenvalues, a consequence of the Hermitian nature of the selector $\Gamma$, and vice versa. Thus, if a genuine metronic eigenvalue problem exists—that is, if all eigenvalues lie within a discrete point spectrum—then all eigenfunctions must converge, and the functional selector must be Hermitian. If this is the case, the discrete eigenvalues become real and consequently describe real, quantum-like states of the underlying metronic hyperstructure. Whenever a structural state is described that is characterized by stationary quantum levels, it is possible to describe this state using a Hermitian functional selector that acts on a convergent state function $\varphi$ in such a way that a metronic eigenvalue problem $\Gamma ; \varphi=\lambda \varphi$ arises,  which, due to $\varphi=\psi ; n$, can be expressed as a general selector equation $\Gamma ; \psi=\lambda \psi$. $\Gamma$ describes the state of the structure and, if the Hermitian condition is satisfied, is referred to as a state selector, while the discrete levels $\lambda$  of the state are described by the metronic eigenfunctions $\varphi=\psi ; n$. If $v$ is the quantum number of a level $\lambda_{v}$, which is described by $\varphi_{v}$, then $\left\lceil; \varphi_{v}=\lambda_{v} \varphi_{v}\right.$ always holds. If $\mu \neq v$ is a different level, then $\varphi_{\mu}^{*} \Gamma ; \varphi_{\nu}=\lambda_{\nu} \varphi_{\nu} \varphi_{\mu}^{*}$ would describe the transition from one level to the other, but $\underset{\Omega}{\boldsymbol{S}} \varphi_{\mu}^{*}\left\lceil; \varphi_{\nu} \partial \Omega=0\right.$ or, because of $\lambda_{\nu}=$ const, also results in $\boldsymbol{S}_{\boldsymbol{\Omega}} \varphi_{\nu} \varphi_{\mu}^{*} \delta \Omega=0$. Due to the convergence  $\boldsymbol{S}_{\Omega} \varphi_{\nu} \varphi_{\nu}^{*} \partial \Omega=1$ for $\mu=\nu$ it can generally be set that $\boldsymbol{S}_{\Omega} \varphi_{\mu} \varphi_{\nu}^{*} \delta \Omega=\delta_{\mu \nu}$, provided that $\Gamma$ acts linearly. In this case, the eigenfunctions form a normalized orthogonal system; that is, there actually exists, over the underlying $N$-dimensional hyperstructure, in which Hermitian state selectors act.
