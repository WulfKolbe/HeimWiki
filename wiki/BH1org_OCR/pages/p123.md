In $\varphi=\varphi\left(n_{i}\right)_{1}^{L}$, $\varphi$ is explicitly given by the $n_{i}$ of the metronic $R_{L}$, but there can also be an implicit combination of the $n_{i}$ with $\varphi$ in the general form $F\left(\varphi, n_{i}\right)_{1}^{L}=$ const. Because $F=$ is constant, $\partial F=0$ is true in any case, as is $\partial F=\partial_{\varphi} F+\sum_{i=1}^{L} \partial_{i} F$, so  $\mathfrak{ð}_{\varphi} F+\sum_{i=1}^{L} \mathfrak{d}_{i} F=0$. This contains $\partial_{\varphi} F=f\left(\partial \varphi, \varphi, n_{i}\right)_{1}^{L}$, which, when substituted,  yields $f\left(\partial \varphi, \varphi, n_{i}\right)_{1}^{L}=-\sum_{i=1}^{L} \partial_{i} F$ , from which $\partial \varphi$ may be easier to eliminate than $\varphi$ from $F=$ const. If not only $F=\mathrm{const}$ but also $\varphi=$ is assumed to be constant, then $\partial F=\sum_{i=1}^{L} \partial_{i} F=0$ and  $\partial \varphi=0$, which implies $f\left(0, \varphi, n_{i}\right)_{1}^{L}=0$. This relationship is fundamentally satisfied if $\partial_{\varphi} F \sim \partial \varphi$; because then $f=0$ must always be equal to  $\partial \varphi=0$.
