Before a metric theory can be developed, it is necessary to extend the conceptual framework of the metronic tensor and to investigate the possible dimensions of metronic tensors. If the metron is given by $\tau>0$ in a $R_{p}$ as an element, then these metrons are bounded by the $(p-1)$-dimensional hypersurfaces $x_{p}=y\left(x_{i}\right)_{1}^{p-1}$, which, with a  set parameter $t$, form the hypersurface set $f\left(x_{i}, t\right)_{1}^{p}=0$ in Euclidean  form in $R_{p}$, such that the condition of continuous connection  of the $p$-dimensional metrons $\tau>0$ is satisfied. The $R_{p}$, which is thus coordinated with each of the $t$ values allowed for $\tau$, must then, with respect to a volume, be an integer multiple of $\tau$, which results in an integer division of the $1 \leqq i \leqq p$ coordinates $x_{i}$ in accordance with $x_{i}(n)$. The integer sequence $n$ falls within the  metronic range $1 \leqq n \leqq N$, while the $p$ grid $x_{i}(n) \hat{=} x_{(i) n}$ can be described as a simple, primitively structured, metronic tensor. Such a simple tensorium is therefore always $p$-dimensional and is spanned by $p$ coordinates $x_{(i) n}$, which, as metronic grids, are number-theoretic functions of the integer metron number $n$. In the explicit case, this is evident from 
$\int \prod_{\omega}^{p} d x_{i}=n \tau$, but in the implicit case, $f\left(x_{i}, t\right)_{1}^{p}=0$, the parameter $t$ must be eliminated.
