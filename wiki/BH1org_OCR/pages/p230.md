With the separation constant $a=$ const, the following holds for the differential equation of the $R_{3}$ structure  $\sum_{k=1}^{3} \frac{\partial^{2} w}{\partial x_{k}^{2}}+\frac{i}{2} \sum_{k=1}^{3} \lambda_{k} \frac{\partial w}{\partial x_{k}}-a w=0$. If the normalized orthogonal system $\vec{e}_{i} \vec{e}_{k}=\delta_{i k}$ is used, then in addition to $\vec{\lambda}=\sum_{k=1}^{3} \vec{e}_{k} \lambda_{k}$, $\sum_{k=1}^{3} \vec{e}_{k} \frac{\partial}{\partial x_{k}}=\operatorname{grad}$ and $\sum_{k=1}^{3} \frac{\partial^{2}}{\partial x_{k}^{2}}=$ divgrad can be introduced, so that the differential equation takes the form divgrad $w+\frac{i}{2} \vec{\lambda} \operatorname{grad} w-a w=0 \quad$. If there is complete spherical symmetry in $R_{3}$ with $d R^{2}=\sum_{k=1}^{3} d x_{k}^{2}$, then, after a transformation to polar coordinates, if $\lambda_{R}=\underline{\lambda}$ is used for reduction and $F(R)$ is used as the derivative $\frac{d F}{d R}=F^{\prime}$, then $w^{\prime \prime}+2 w^{\prime} / R+\frac{i}{2} \underline{\lambda} w^{\prime}-a w=0$, with $w=w(R)$. If  $f(R)=2 / R+i \underline{\lambda} / 2$, then $w^{\prime \prime}+f w^{\prime}-a w=0$ holds, and in this expression,  can be substituted with $w=e^{H}$, where $H(R)$ holds. This substitution yields $\quad a=H^{\prime \prime}+H^{\prime 2}+f H^{\prime}=H^{\prime \prime}+\left(H^{\prime}+f / 2\right)^{2}-f^{2} / 4$. A further substitution $U=H^{\prime}+f / 2$ or $H^{\prime}=U-f / 2$ then yields $U^{\prime}+U^{2}=a+f^{2} / 4+f^{\prime} / 2$. Because of $f=2 / R+i \underline{\lambda} / 2$, $F(R)=a-\underline{\lambda}^{2} / 16+\frac{i \underline{\lambda}}{2 R}$ can be used, so that the spherically symmetric $R_{3}$structure is described by $d U / d R+U^{2}=F(R)$,  provided that $U=H^{\prime}+f / 2$ and $H=\ln w$ hold.
