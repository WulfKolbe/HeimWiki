As shown above, since all $R_{12}$ coordinates must have the same dimensions, $\Delta x_{7} \sim \delta l_{7}\left(\alpha \delta l / \delta l_{0}\right)^{i}$ and $\Delta x_{8} \sim \delta l_{8}\left(\alpha \delta l / \delta l_{0}\right)^{-i}$, where the elements $\delta l_{0}, \delta l_{7}$ and $\delta l_{8}$ still need to be determined. $\Delta$ denotes differences that can still be divided,  while $\delta$ denotes elementary quantities, so that the proportionality factors are generally  only integers $(\geqq 1)$. The element $\delta l_{0}$ could be a  time function. If this is assumed, then $\delta l_{0}(t)$ would hold; however, in $\pi D^{2}=n \tau$ also contain $D, n$ and $\tau$ as such time functions, so that $\delta l_{0}(t)=\delta l_{0}(n(t))=\delta l_{0}(\tau)=\delta l_{0}(\delta l)$ would have to hold. However, this would contradict the proportionalities of $\Delta x_{7}$ and $\Delta x_{8}$  $\mathrm{zu}(\delta l)^{ \pm i}$, from which it follows that $\delta l_{0}$ must be time-independent. Such time-independence would be achieved by $\delta l_{0}=\sqrt{\pi D_{1} \overline{d_{1}}}$, which numerically yields $\delta l_{0}=1,4312488$ in $[m]$. The proof of the time-independence of this element $\delta l_{0}$ can be carried out using the methods developed in IV., 4. This yielded the diameters $D$ and $D^{\prime}$ according to (37) and (37a), which are related to the metronic elements $\sqrt{\tau}$ and $\sqrt{\tau^{\prime}}$. Specifically, $D \sqrt{\tau^{\prime}}=D^{\prime} \sqrt{\tau}$ and $D ' \sqrt{\tau}=E \cdot \pi / e$ were obtained. This relationship holds for all $t$, including $t=0$.
