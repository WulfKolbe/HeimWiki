# Equation BH1org_OCR_EQ0094

$$
\begin{aligned} & C_{i_{k} \cdots i_{m}}=\prod_{k=1}^{m} C_{i_{k}}, \text { derart, daß die Darstellung } \\ & \prod_{k=1}^{m} C_{i_{k}}=\prod_{k=1}^{l-2} C_{i_{k}} ; C_{l-1} ; C_{l} ; \quad \prod_{k=l+1}^{m} C_{i_{k}} \text { mit } C_{i_{l}}=C_{l} \text { möglich } \end{aligned}
$$
